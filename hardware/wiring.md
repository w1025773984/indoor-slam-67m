# 硬件接线文档

## 阶段 1 接线

### RPLIDAR A2 → 笔记本

```
┌─────────────────┐
│  RPLIDAR A2     │
│  （带 12V 适配器  │
│   + USB 数据线） │
└────────┬────────┘
         │ USB
         ↓
    ┌─────────────┐
    │  笔记本      │
    │  /dev/rplidar│
    └─────────────┘
```

**注意**：
- RPLIDAR A2 内部电机需要 5V/1A，**必须** 用 USB 口有足够供电能力（蓝色 USB 3.0 通常 OK，老式 USB 2.0 可能带不动）。
- 如果笔记本 USB 供电不足，会出现"雷达转一下就停"或"完全没扫描"，可以加一根 USB Y 线（一个头供电，一个头数据）。
- 67 平米家用，雷达放在三脚架上离地 1.2–1.5 m 是好位置，能避开地面反射和大部分家具遮挡。

### ESP32（阶段 2 接入底盘）

阶段 1 不接底盘，ESP32 只是放在桌上跑个串口自测。

阶段 2 接线（参考）：

```
┌──────────────┐         ┌────────────────┐
│  ESP32        │  UART   │  L298N 电机驱动 │
│  DevKitC V4   ├─────────┤  (差速底盘)     │
└──────┬───────┘         └────────┬───────┘
       │ Micro USB                  │ 12V 电池
       ↓                            ↓
   笔记本 /dev/slamtak          12V 锂电池组
```

- ESP32 GPIO 17/18 → L298N IN1/IN2（左电机）
- ESP32 GPIO 16/19 → L298N IN3/IN4（右电机）
- ESP32 GPIO 34/35 → 编码器（左/右电机）
- ESP32 GPIO 21/22 → I2C MPU6050 IMU（可选）

详细阶段 2 接线会在 `hardware/phase2_wiring.md` 补充（未开始）。
