## 关键选型说明

### RPLIDAR A2M8 vs A2M12 vs A1

- **A1（4m 量程）**：太近，67 平米的家经常扫到墙另一边，不要买。
- **A2M8（12m 量程）**：家用最合适，性价比最高。**推荐**。
- **A2M12（16m 量程）**：价格贵一点（¥1100–1300），增益不大，67 平米用不到。
- **A3（25m 量程）**：户外用，家用浪费。

### 注意事项

1. **接口**：A2M8 标准版是 USB 接口，直接插电脑即可。如果买的是带 UART/USB 转接板，要保留转接板。
2. **供电**：USB 自带供电，不需要额外电源。
3. **驱动版本**：思岚官方 `rplidar_ros2` 包，ROS2 Humble 直接用。
4. **固件**：买回来不要刷固件，出厂即用。

### ESP32 选型

- **ESP32-DevKitC V4**（¥30–50）：经典款，足够用。
- **NodeMCU-32S**（¥40）：也行。
- **阶段 1 不用接底盘**，可以先不买；但 ¥40 不贵，建议提前备好。

## 接线

### RPLIDAR A2 → 笔记本

```
RPLIDAR A2 雷达本体 ── USB 线 ── 笔记本 USB 口
                ↓
         /dev/ttyUSB0 (Linux)
         /dev/rplidar  (udev 别名，配好 udev 后)
```

### ESP32 → 笔记本（阶段 2 备用）

```
ESP32 DevKit ── Micro USB 线 ── 笔记本 USB 口
            ↓
      /dev/ttyUSB1
      （阶段 2 用于电机控制 + 编码器 + IMU）
```

阶段 1 阶段 ESP32 暂不接线，只放在桌面上跑个简单的串口测试就行。

## udev 规则（必须配）

雷达和 ESP32 每次插入都会变 `/dev/ttyUSB*`，配 udev 后可以稳定使用 `/dev/rplidar` 和 `/dev/esp32` 别名。

执行 `scripts/setup_udev.sh` 一键配置，详见 `docs/INSTALL.md`。
