## 关键选型说明

### 1. RPLIDAR A2 vs A3 vs S1

- **A2M8（12m 量程）**：家用最合适，性价比最高，**推荐**
- **A1（4m）**：太近，67 平米不够用
- **A3（25m）**：户外用，家用浪费
- **S1（40m，TOF）**：贵 ¥3000+，家用不需要

### 2. 差速底盘

60cm 级推荐规格：
- 长 × 宽：60 × 40 cm
- 驱动轮直径：≥ 12 cm（带编码器）
- 万向轮：1-2 个
- 载重：≥ 10 kg
- 电机：12V 直流有刷电机 + 编码器（500-1000 线）
- 电池仓：容纳 12V 5Ah 锂电池

**淘宝推荐搜索关键词**："ROS 移动机器人底盘 差速 带编码器"

### 3. IMU 选型

- **BMI088**（Bosch，6 轴）：高精度，低噪声，**推荐用于 SLAM**
- **MPU6050**（InvenSense）：便宜但精度差，新项目不用
- **ICM-20948**（TDK，9 轴）：含磁力计，户外场景有用
- **BNO055**（Bosch，9 轴）：带融合算法，更贵但开箱即用

### 4. ESP32 选型

- **ESP32-DevKitC V4**（Espressif 官方）：经典款，¥30-50
- **NodeMCU-32S**：也行
- 固件开发用 ESP-IDF（推荐）或 Arduino

### 5. 电池选型

- 12V 5Ah 锂电池组（带 BMS 保护板）
- 续航：1.5-2.5 小时（取决于电机功率 + 雷达功耗）
- 注意：电池要**降压到 5V** 给雷达和 ESP32 供电（用 DC-DC 模块）

## 接线

### 系统架构

```
┌──────────────────── 上位机（决策层）────────────────────┐
│ Ubuntu 22.04 + ROS2 Humble                            │
│ - slam_toolbox（建图 / 定位）                          │
│ - robot_localization（多源融合）                       │
│ - Nav2（路径规划 + 避障）                              │
│ - 状态机 + 行为树                                     │
│ - RViz2（调试可视化）                                 │
└────┬─────────────────────┬───────────────────────────┘
     │ USB               │ WiFi / SSH（笔记本调试）
     │                   │
┌────▼───────────────────▼───────────────────────────┐
│ ESP32（实时控制层）                                  │
│ - PID 控制 2 个直流电机                              │
│ - 读编码器（左右轮）                                 │
│ - 读 BMI088 IMU（I2C）                              │
│ - 通过 micro-ROS 把 /odom / /imu 发给上位机         │
└────────────────────────────────────────────────────┘

       ┌──────────┐
       │ RPLIDAR  │ USB 直连上位机
       │   A2     │
       └──────────┘
```

### RPLIDAR A2 → 笔记本

```
RPLIDAR A2 ── USB ── 笔记本 /dev/rplidar
```

### ESP32 → 笔记本（无线调试 + 通信）

```
ESP32 ←─ WiFi / 串口 ─→ 笔记本
   ↑                       ↑
   │ I2C                   │
   ↓                       │
BMI088 IMU            micro-ROS agent
```

### ESP32 → 电机驱动 + 编码器

```
ESP32 GPIO 25/26 ── L298N IN1/IN2（左电机）
ESP32 GPIO 32/33 ── L298N IN3/IN4（右电机）
ESP32 GPIO 34/35 ── 编码器 A/B 相（左电机）
ESP32 GPIO 36/39 ── 编码器 A/B 相（右电机）
```

### 电源

```
12V 5Ah 锂电池
├── 直接 → L298N 电机驱动（VM）
├── DC-DC 降压 5V → RPLIDAR A2 电源
├── DC-DC 降压 5V → ESP32（VIN 引脚）
└── DC-DC 降压 3.3V → BMI088（VCC）
```

## udev 规则（必配）

雷达和 ESP32 每次插入会变 /dev/ttyUSB*，配 udev 后用稳定别名：

- `/dev/rplidar` → RPLIDAR
- `/dev/esp32` → ESP32 micro-ROS 串口

执行 `scripts/setup_udev.sh` 一键配置。
