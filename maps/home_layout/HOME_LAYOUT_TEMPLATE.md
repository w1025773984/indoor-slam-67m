# 67 平米户型 + 测试场景模板

## 第一步：测量 + 画户型图

打开 draw.io（https://app.diagrams.net/）画一张你家的户型图。
或者用纸笔画一张，拍给我。

**最小数据需求**：
- 各房间的尺寸（米，墙到墙距离）
- 门的位置和宽度
- 家具大致位置（沙发、桌子、床、衣柜）
- 起点位置（机器人充电桩放在哪）

## 第三步：规划扫图路径

### 第一次扫图（M1-W2）

**目标**：拿到一份可用的 67 平米地图

**路径**：
1. 起点（机器人开机位置）→ 沿墙根走一圈
2. 顺序：客厅 → 主卧 → 次卧 → 走廊 → 厨房 → 卫生间 → 回到起点
3. 速度 ≤ 0.3 m/s（要慢）
4. 关键回环点：起点、走廊交叉处、每个房间门口

**易出错位置**：
- 玻璃门：扫图时关门或贴磨砂膜
- 镜面：用布遮挡
- 黑色家具：多走两遍
- 反光瓷砖：雷达微抬 5°

### 后续复扫（M1-W3）

**目标**：验证地图精度（3 遍重合率 > 95%）

每次走同一路径，保存 3 张地图，对比一致度。

## 第四步：设计测试场景（M2-W4 起）

### 场景 1：单点导航（基线）
**目标**：起点 → A 点（客厅）
**验收**：5 次连续测试，5 次到达成功率
**测什么**：路径规划合理性

### 场景 2：多点巡航
**目标**：起点 → A → B → 起点
**验收**：完整跑通率
**测什么**：多目标点切换

### 场景 3：动态避障（人在家）
**目标**：机器人在客厅巡航，地面随机走动
**验收**：机器人不停撞、重新规划路径
**测什么**：局部避障

### 场景 4：自主回充（M3-W1）
**目标**：起点 → 回充电桩
**验收**：对接成功率 > 90%
**测什么**：最后 1 m 精度

### 场景 5：异常恢复（M3-W2）
**目标**：让机器人"卡住"，看能否自己脱困
**验收**：卡住后 30 秒内脱困
**测什么**：异常检测

### 场景 6：72h 稳定性（M3-W3）
**目标**：机器人自主巡航，7×24 小时
**验收**：0 次宕机，0 次需要人工干预
**测什么**：长期稳定性
